Taxes, Explained Plainly

Manitoba Just Started Taxing the Cloud

Since January 1, 2026, the province charges 7% RST on SaaS, cloud storage, and hosting. If you buy software — or build and sell it — here's what changed, straight from the province's own Bulletin 033.

What changed on January 1, 2026

Before this year, if your business merely accessed software running on a server outside Manitoba — which is what almost every cloud subscription is — the charges weren't subject to Manitoba Retail Sales Tax. Software downloaded onto a Manitoba computer already was taxable.

That gap closed. Manitoba revised its Bulletin 033 (Computer Software and Online Services, revised January 2026) so that charges for cloud computing are taxable effective January 1, 2026. That explicitly includes:

  • Software as a Service (SaaS)
  • Platform as a Service (PaaS)
  • Infrastructure as a Service (IaaS)
  • Cloud storage
  • Website hosting
  • Video game subscriptions

The tax applies when the software or service is used on a device — or by a person — ordinarily situated in Manitoba. For a phone, that means a Manitoba area code. On top of the 5% GST that already applied, a $50/month subscription now bills as $50 + $2.50 GST + $3.50 RST = $56.00.

One grandfathering rule worth knowing: payments made before January 1, 2026 for a service period that began before that date are not taxable — even if the period runs into 2026. Annual subscriptions prepaid in December 2025 escaped the increase.

What's taxable vs. what's exempt

Taxable (7% RST):

  • Packaged or prewritten software, and the right to use it
  • Cloud computing: SaaS, PaaS, IaaS, cloud storage, website hosting
  • Modifications to prewritten software (unless so extensive the modification charges exceed the cost of the prewritten software itself)
  • Remote configuration, installation, or troubleshooting services performed on taxable software
  • Maintenance, warranty, and support contracts for taxable software

Exempt:

  • Custom software designed and developed for a specific person — and the programming services related to it
  • Optional services like training, consulting, data processing, and help-line support — if shown as a separate line on the invoice and not a condition of the software purchase
  • Website domain names and website design, when purchased separately from the hosting
  • Certain services between related corporations, effective January 1, 2026

Three traps that catch small businesses

1. Mixed support contracts are fully taxable unless you itemize. If a maintenance or support agreement bundles taxable and exempt services, the province treats the whole contract as taxable — unless the exempt services are described and shown as separate lines on the invoice. One clean invoice line can be the difference between 7% on everything and 7% on the right thing.

2. Remote help on taxable software is taxable. If a consultant connects remotely to your equipment and configures, installs, or troubleshoots taxable software, RST applies — even if the consultant is outside Manitoba.

3. Multi-province usage can be prorated. If software is used both inside and outside Manitoba, RST may be prorated based on the share of licences or users located here. Worth knowing if your team spans provinces.

4. Reselling copies — or reusing a build for another client — loses the exemption. A copy or licence of custom software is taxable when sold to anyone other than the specific person it was built for, and a program built for several customers in one industry does not qualify as custom software at all. If what you built might serve many customers, it is a product, not a custom build — invoice it accordingly.

If you build and sell software in Manitoba

The province requires providers of SaaS, PaaS, and IaaS — resident or not — to collect RST when selling for use in Manitoba. In practice that means registering with Manitoba Finance and adding the 7% to invoices for Manitoba customers. And if you also buy cloud services to run your own operation, note that providers can't treat those as purchases for resale — the tax applies to what you consume, too.

If you sell custom, built-for-one-client software, the exemption is your friend — but keep the lines clean: the custom development on one line, any hosting or cloud charges on another.

Frequently asked questions

Is software as a service (SaaS) taxable in Manitoba?

Yes. Effective January 1, 2026, Manitoba charges 7% RST on cloud computing — SaaS, PaaS, IaaS, cloud storage, and website hosting — on top of the 5% GST that already applied.

Is custom software taxable in Manitoba?

No. Per Bulletin 033, custom software developed solely for a specific person — and the programming services around it — is exempt from RST. Packaged or prewritten software remains taxable, and copies sold to other customers are taxable.

How much is RST in Manitoba?

7%. On a $50/month subscription: $50 + $2.50 GST + $3.50 RST = $56.00. Payments made before January 1, 2026 for periods that started before that date aren't subject to the new tax.
